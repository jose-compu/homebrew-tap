# jose-compu/homebrew-tap

Homebrew formulae for [jose-compu](https://github.com/jose-compu) tools.

## rustmaninoff

```sh
brew install jose-compu/tap/rustmaninoff
rustmaninoff scan .
```

Formula tracks GitHub Release binaries from [jose-compu/rustmaninoff](https://github.com/jose-compu/rustmaninoff).
